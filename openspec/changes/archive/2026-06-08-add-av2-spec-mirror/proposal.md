# Change: add-av2-spec-mirror

## Feature IDs

- `DOC-AV2-SPEC-MIRROR`

## Why

`splot` is spec-first: every syntax element must trace to the AV2 v1.0.0
specification, and AGENTS.md forbids inventing syntax, constants, or semantics.
Today that spec lives only as an external PDF/HTML at `av2.aomedia.org`. Code
comments cite `§` numbers, but there is no committed, offline, greppable copy of
the normative text, so "ground every claim in the spec" depends on network
access and human memory. Agents and reviewers cannot quote or diff the exact
normative wording from within the repository. A committed, versioned mirror makes
the specification the enforceable single source of truth.

## What Changes

- Add a committed, versioned mirror of the AV2 v1.0.0 specification under
  `docs/spec/av2/1.0.0/`, generated by a faithful `pdftotext -layout` conversion
  of the official PDF and split into one Markdown file per chapter/annex, with
  `§ N.M` headings layered over **verbatim** fenced bodies (byte-exact spec text).
- Add `docs/spec/av2/1.0.0/index.md` mapping every `§` heading to its
  `file#anchor` and page number, plus `provenance.toml` (PDF URL + sha256,
  poppler version, conversion args) and a `CHECKSUMS` integrity manifest.
- Add a standalone regeneration script `scripts/spec/regenerate-av2-spec.sh`,
  parameterised by version + URL + expected sha256 (markitdown is **not**
  vendored; the conversion uses poppler's `pdftotext`, evaluated as higher
  fidelity).
- Add a `cargo xtask check-spec-mirror` integrity gate, wired into `cargo xtask
  ci`, that verifies the committed files match `CHECKSUMS` and that
  `provenance.toml` pins the expected PDF hash (deterministic; no poppler needed).
- Wire the mirror in as the single source of truth: a new AGENTS.md rule,
  `docs/SPEC-MAPPING.md` source list update, a `docs/references/THIRD-PARTY-NOTICES.md`
  entry quarantining the mirror as AOM-copyright material (**not** PolyForm), and
  a `_typos.toml` exclude for `docs/spec/**`.

## Capabilities

### New Capabilities

- `av2-spec-mirror`: the committed, versioned, byte-faithful AV2 specification
  mirror; its provenance, integrity gate, regeneration reproducibility, and
  third-party-license quarantine.

### Modified Capabilities

- `process`: development must ground AV2 syntax/semantics claims in the committed
  spec mirror as the canonical offline source of truth.

## Non-goals

- No AV2 syntax, reconstruction, reference-state, or layer behavior is
  implemented or changed; this is documentation + tooling only.
- No change to the one-way `splot-*` crate dependency direction (the gate lives
  in the existing `xtask` crate). It adds one external dependency — the
  well-vetted `sha2` crate — to `xtask` for hashing (maintainer-approved; do not
  hand-roll crypto primitives).
- No transformation that could alter normative wording: prose is **not**
  reflowed into prose Markdown; spec bytes are preserved inside fences.
- No mirror of any AV2 version other than v1.0.0 (future versions are new,
  independent `docs/spec/av2/<version>/` directories).
- No relicensing: the mirror stays AOM-copyright and isolated; the rest of the
  repository remains PolyForm Noncommercial 1.0.0.

## Impact

- New files under `docs/spec/av2/1.0.0/` (~3.5 MB of spec text across ~25 files),
  `scripts/spec/regenerate-av2-spec.sh`.
- Modified: `xtask/src/main.rs` (new `check-spec-mirror` subcommand + CI wiring),
  `xtask/Cargo.toml` + root `Cargo.toml`/`Cargo.lock` (`sha2` dependency),
  `AGENTS.md`, `docs/SPEC-MAPPING.md`, `docs/references/THIRD-PARTY-NOTICES.md`,
  `_typos.toml`, `docs/IMPLEMENTATION-MATRIX.toml` (new `DOC-AV2-SPEC-MIRROR` row).
- Validator impact: none directly; enables future spec-grounded diagnostics to
  cite the committed mirror. No new runtime diagnostics or `rule_id`s.
- Licensing: introduces an approved mixed-license exception (AOM specification
  text) recorded in THIRD-PARTY-NOTICES; maintainer-approved.
