2026-11-13, push 2 (deadlock fix, T4 tests):
1. DEADLOCK FIX, shared code (the user asked for it on this branch). Commit
   "fix(decode): release idle frame work before the frame store waits".
   x86-shared: crates/splot-decode/src/pipeline/mod.rs (1 line in the store-full branch
   of the frame loop), crates/splot-decode/src/pipeline/frame_tasks.rs (`release_idle`
   next to `SamplePools::drain` and in `impl RowPools`, plus one unit test).
   Root cause: the frame store has 2 * MAX_REF_FRAMES + depth + 1 entries. A finished
   `SplitFrame` (also a TIP and a finish slot) keeps the reference state and the motion
   and product handles of its last frame until `reserve` resets the slot for the next
   frame. That reuse needs a free store entry first. At an effective depth of 16
   (min(frame delay, workers)) on the two streams the idle slots pin all 49 entries: the
   driver waits for an entry and no thread can release one. Proof at the hang: a reset of
   the 16 idle split slots gives `has_space` and the decode completes; a reset of the TIP
   slots only does not.
   The fix: when the store is full, the driver resets each idle slot (`Arc::get_mut`
   succeeds) with the reset that reuse does, then reclaims. No cap on threads or depth.
   Checks on x86: the two streams complete at 16, 17, 20, 32 threads and at frame delay
   16 and 20; hashes equal at 1, 5, 16, 20 threads; stress 3,200 decodes at 2, 3, 4, 20
   threads, 0 failures, 0 timeouts; wall time at 8 and 20 threads inside the noise.
   If your fix is different, keep yours and drop this commit; tell me in the handoff.
   Related weakness, not changed: `WorkPool::reserve` resets only the first idle slot,
   and the store size assumes that only live work pins frames.
   Please run the aarch64 hashes and your 15 / 16 thread case with this commit.
2. T4 is complete: no defect in an AVX2 kernel. Each AVX2-TOUCHED kernel fails a test when
   it is broken on purpose. Commit "test(recon): check the AVX2 kernels on more shapes and
   extreme inputs" adds tests only (6 test files; they compile on aarch64, clippy clean).
   The new shapes in `subpel_mc/tests/byte_lanes.rs` and the all-maximum plane in
